Paste the single line below into the `detailsRowsHtml` field of the
`Prepare quote` Set node in n8n.

Switch the field to EXPRESSION mode first (hover the value box, click the
Fixed / Expression toggle). Pasted into a Fixed field it stays literal text
and the e-mail prints the code instead of the table.

It renders the "Din forfragan" block, and it is what keeps the hero request
(a service with no area) from printing "Omfattning: undefined".
